# Сценарій захисту Luden

| Етап | Що показати | Час |
| --- | --- | ---: |
| Вступ | Мета релізу, ролі команди, вісім історій та критерії приймання | 45 с |
| Основний маршрут | Вхід, каталог, Atlas Drift, кошик, симуляція оплати, бібліотека | 2 хв |
| Індивідуальний внесок | Кожен показує артефакт зі своєї зони та перевіряє один сценарій з [листа команди](../TEAM.md) | 5–7 хв |
| Рев’ю | Показати кейс кнопки та вимогу про бонуси. Зіставити два кадри кошика й відкрити [повний лог реплік](AI_Interaction_Log.md) | 2 хв |
| Підсумок | Зіставити результати прототипу з тестами застосунку. Назвати відкриті перевірки | 1 хв |

Запис додати до README після фактичного проходження захисту.
