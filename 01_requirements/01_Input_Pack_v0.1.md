## Source Check для контролю A

Включено US-01…US-08 і 33 критерії приймання. Для US-07 визначено п’ять критеріїв, для решти історій — по чотири. Розподіл за екранами та тестами наведено в [Traceability](../02_architecture/03_Screen_Contracts.md#traceability). Відкладені сценарії перелічено в [межах S1-LUDEN](00_Product_Baseline.md#межі).

- **Q-01.** Чи входить до захисту окремий кадр реєстрації, якщо основний маршрут починається зі входу?
- **Q-02.** Чи достатньо симуляції оплати для оцінювання або потрібен прогін Stripe Test Mode?
- **Q-03.** Чи потрібна для користувача окрема дія «Очистити пошук» у порожньому стані? Реалізація вже дозволяє видалити запит у полі.
- **Q-04.** Які приклади станів каталогу потрібні в Figma як повні кадри, а які достатньо показати в довідці станів?
- **Q-05.** Чи потрібні сценарій адміністратора й кадр відмови за роллю, окрім матриці прав?
