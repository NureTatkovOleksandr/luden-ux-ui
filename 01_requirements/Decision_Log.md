# Журнал рішень Luden

**Редакція:** timbuhtuk · 2026-11-07. Зафіксовано поведінку HTML-прототипу й окремо зріз оновленої Figma.

IMPLEMENTED означає наявність поведінки у вихідному коді, а не пройдений тест або погодження викладача. DOCUMENTED означає редакційне уточнення вимог. OPEN означає невирішене питання. OBSERVED означає наявність кадру чи налаштування у Figma; це не результат проходження Present. D-01…D-08 із IMPLEMENTED стосуються HTML, а не Figma. Попередній загальний статус PROPOSED замінено цими точнішими позначеннями; приймання рецензентом окремо не зафіксовано.

| Q-05 | DOCUMENTED | Макет Admin відкладено. Матриця та API-перевірка прав лишаються вимогами; гостьова навігація продукту ще не покрита прототипом |

| Q-07 | OPEN | Визначити значення Paid і Completed, початковий статус, події й допустимі переходи, обробку відмови. Поточне правило доступу не є повною моделлю замовлення |

| Q-10 | OPEN | Встановити критерії приймання доступності: клавіатура, фокус, контраст і читабельність; записати метод та результат перевірки |
| Q-11 | OPEN | Узгодити правило пароля: Figma показує «Щонайменше 8 символів», але Input Pack не задає довжину. Зафіксувати обмеження, помилки й однакову валідацію форми та API |

Для погодження приймання додати рецензента, дату, версію та перелік закритих Q-ID. Редакційне виправлення не підміняє це погодження.
